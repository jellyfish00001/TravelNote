# 專案規範與 Agent 行為偏好指南 (TravelNote AGENTS.md)

本文件定義了本專案（曼谷自由行行程規劃 / TravelNote）的各項資料處理原則、Excel 產出格式、排版風格規範與版本控制流程。後續所有 Agent 在讀取、修改、新增對話內容或擴充行程時，**必須無條件嚴格遵守以下準則**，避免重蹈先前誤解需求的錯誤。

---

## 🛑 核心禁止行為 (Strict Prohibitions)

1. **嚴禁擅自臆測與塞入未確認地點**：
   - 若對話或筆記中未指明具體店家或飯店（例如僅寫「先去 check in」、「可排咖啡廳或晚餐」、「夜市或按摩」），**「實際地點」欄位必須嚴格保持空白**，保留時段與想法即可，絕不可自行猜測補上景點或飯店名稱。
2. **嚴禁擅自擴展行程天數**：
   - 預定計畫行程僅能排入文字對話真正有討論的日期（如目前的 11/25 週三 ～ 11/27 週五共 3 天）。若對話未排定後續天數，絕不可自行補排 Day 4、Day 5 等自創行程。
3. **嚴禁在備註欄位出現特定人名**：
   - 備註中**一律不得提及是誰說的、誰推薦的或誰的偏好**（嚴格去除如「🍑Mo 提起」、「Jerry 推薦」、「丁 建議」等特定姓名標記）。
   - 備註僅保留 1~2 句純客觀評語、景點特色重點與預約訂位提醒。
4. **嚴禁繁複過度的花俏排版**：
   - 除最頂部大標題與欄位標頭可使用沉穩深色主題樣式外，資料列一律維持乾淨純白背景 (#FFFFFF) 與標準細灰格線，不使用交替色底或花俏底色。

## 📊 Excel 工作表架構與欄位規範

### 工作表 1：曼谷行程心願清單
1. **標題列 (Row 1)**：🇹🇭 曼谷自由行心願清單（置中、深藍灰 #2C3E50 底白字）。
2. **標頭列 (Row 2)**：直接接續標頭欄位，**嚴禁在第二列加入任何「整理依據...」等長篇說明文字**。
3. **欄位順序（嚴格固定由左至右 7 欄）**：
   - **Column A：類別** ➔ 嚴格限定劃分為三種分類：**「景點」**、**「美食」**、**「住宿」**。
   - **Column B：地點名稱** ➔ **中文優先使用群組留言稱呼**（如「高空酒吧」、「夕陽晚餐峇里島風」、「超貴牛逼網美遊艇」等），並附上英文或官方地名；**直接在此欄文字嵌入 Google Maps 導航超連結**，不設獨立地圖欄位。
   - **Column C：城市 / 分區** ➔ 標明所在城市及分區（如芭達雅・帕山、曼谷・通羅等）。
   - **Column D：營業時間 / 建議時段** ➔ 營業時間及推薦造訪時段。
   - **Column E：行程安排標記** ➔ 僅標記真正有排入暫定行程的地點（如 暫定 11/25 (三) 晚餐、暫定 11/26 (四) 半日遊），未明確排入者一律顯示 -。
   - **Column F：備註** ➔ 純客觀評語（無人名），包含 1~2 句特色重點、必拍角度、訂位與穿著提醒。
   - **Column G：圖片** ➔ **必須位於表格最後一欄**，置中嵌入標準化實景縮圖（約 110x72 px）。
4. **移除冗餘**：不設「項次」、不設「原始對話出處」、不設「特色重點介紹」獨立欄位。

### 工作表 2：預定計畫行程
1. **標題列 (Row 1)**：🗓️ 芭達雅自由行 暫定計畫行程表 (11/25 - 11/27)（置中深色底）。
2. **標頭列 (Row 2)**：直接接續標頭欄位，**嚴禁在第二列加入任何冗長說明文字**。
3. **天數限定**：嚴格僅規劃 11/25 (週三) ～ 11/27 (週五) 共 3 天，不擅自增添額外天數。
4. **欄位順序（嚴格固定由左至右 6 欄）**：
   - **Column A：日期 / 星期**（如 11/25 週三）
   - **Column B：時段 / 順序**（如 （1）、（2）、（3）、（4））
   - **Column C：行程想法 / 項目**（如 機場到巴達雅3小時、先去 check in、夕陽晚餐峇里島風、沙灘日等）
   - **Column D：實際地點 (未提及則保持空白)** ➔ 僅填入對話紀錄中已明確指定之地點，其餘未定項目**一律保持空白**。
   - **Column E：交通方式 (後續填充)** ➔ **務必保留此欄位，目前預設全數留白**，方便後續直接填寫。
   - **Column F：備註** ➔ 僅保留原始文字備註（如包車研究預訂來回、先在 KKday 訂好位子等）。

## 🔄 流程與版本控制要求

1. **增修流程**：
   - 若未來有新對話紀錄或更新地點需求，先比對舊有 28 筆清單避免重複。
   - 提取新地點的 Google Maps 真實連結並下載代表性縮圖至 	humbnails/resized/。
   - 使用 openpyxl 更新 d:\曼谷自由行\曼谷自由行心願清單.xlsx。
2. **Git 同步**：
   - 每次修改完成後，更新 README.md。
   - 執行 git add -A、git commit（清晰描述變更）與 git push origin main 推送至 https://github.com/jellyfish00001/TravelNote.git。
