## 📊 Excel 活頁簿內容說明

### 1. 曼谷行程心願清單 (28 處精選地點)
- **簡明欄位設計**：類別、地點名稱、城市 / 分區、營業時間 / 建議時段、備註、圖片。
- **三大清晰分類**：嚴格統一劃分為「景點」、「美食」、「住宿」三類。
- **群組稱呼優先**：地點中文優先採用群組對話中的慣用語（如「高空酒吧」、「夕陽晚餐峇里島風」、「超貴牛逼網美遊艇」等）。
- **Google Maps 直連**：點擊地點名稱文字即可直達 Google Maps 導航頁面。
- **圖片移至最末欄**：照片縮圖置於最後一欄，表格閱覽更流暢。
- **極簡乾淨排版**：保留標準表格網格，去除過度色彩與繁複排版。

### 2. 預定計畫行程 (11/25 ~ 12/01 完整規劃)
- **Day 1 (11/25 三)**：機場專車直奔芭達雅 ➔ 飯店 Check-in ➔ The Oxygen 峇里島風夕陽晚餐 ➔ 步行街夜市
- **Day 2 (11/26 四)**：晨間悠閒泳池 ➔ Elephant Jungle 洗大象餵食半日遊 ➔ The Sky Gallery 鳥巢夕陽 ➔ ZAMA Skybar 女王頭燈光秀
- **Day 3 (11/27 五)**：中天沙灘日（Cave Beach Club 藍色懶骨頭） ➔ Ocean Sky 男模郵輪夕陽秀 ➔ The Garden 168 露天 Live 酒吧
- **Day 4 (11/28 六)**：包車前往曼谷 ➔ 曼谷飯店 Check-in ➔ ICONSIAM 暹羅天地室內水上市場 ➔ 璀璨明珠號晚宴遊船 ➔ Tichuca 水母酒吧
- **Day 5 (11/29 日)**：包車前往佛統府 Bubble in the Forest 水上小馬爾地夫 ➔ Le Du Kaan 56 樓高空泰菜晚宴 ➔ Fake Club 猛男大秀 或 TRIBE 星光沙灘酒吧
- **Day 6 (11/30 一)**：鱷魚頭水上老街「泰國貓貓船」療癒泛舟 ➔ 阿里（Ari）文青街區與 Craftsman Baby Bar ➔ Big C 伴手禮大採購
- **Day 7 (12/01 二)**：悠閒早餐退房 ➔ 機場專車接送與退稅 ➔ 搭機平安返台
