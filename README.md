## 📊 Excel 活頁簿內容說明

### 1. 曼谷行程心願清單 (28 處精選地點)
- **簡明欄位架構**：類別 ➔ 地點名稱 ➔ 城市 / 分區 ➔ 營業時間 / 建議時段 ➔ 行程標記 ➔ 備註 ➔ **圖片（最末欄）**。
- **三大標準分類**：劃分為「景點」、「美食」、「住宿」三類。
- **群組稱呼優先**：地點中文優先採用群組對話中的慣用語（如「高空酒吧」、「夕陽晚餐峇里島風」、「超貴牛逼網美遊艇」等）。
- **Google Maps 直連**：點擊地點名稱文字即可直達 Google Maps 導航頁面。
- **新增「行程標記」欄位**：標記該地點是否已排入暫定行程（例如：★ 暫定 11/25 (三) 晚餐、★ 暫定 11/26 (四) 中午半日遊 等）。
- **去人名化客觀評語**：備註保留實用客觀的評語、特色與訂位提醒，不提及特定發言人。
- **極簡排版**：保留清晰標準格線，除標題與標頭外均為簡約白色背景。

### 2. 預定計畫行程 (11/25 ~ 11/27 芭達雅暫定規劃)
- 忠實依據原始記事本紀錄編排 3 天行程，不擅自增添額外天數：
  - **11/25 (週三)**：機場前往芭達雅（約 3 小時） ➔ 飯店 Check-in ➔ The Oxygen 峇里島風夕陽晚餐 ➔ 芭達雅夜市或步行街（夜店街）。
  - **11/26 (週四)**：早晨設施/早餐 ➔ 12:00~17:00 Elephant Jungle 洗大象與餵食半日遊 ➔ 傍晚海景咖啡廳/晚餐 ➔ 晚間夜市或泰式按摩。
  - **11/27 (週五)**：日間沙灘日（Cave Beach 藍色懶骨頭 / 粉紅沙灘 / Dongtan Beach） ➔ （可選）傍晚海上夕陽郵輪 / 露天音樂酒吧 ➔ 晚上夜市或按摩。
