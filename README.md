## 📊 Excel 活頁簿內容說明

### 1. 曼谷行程心願清單 (28 處精選地點)
- **簡明欄位架構**：類別 ➔ 地點名稱 *(含 Google Maps 超連結)* ➔ 城市 / 分區 ➔ 營業時間 / 建議時段 ➔ 行程安排標記 ➔ 備註 ➔ **圖片（最末欄）**。
- **三大標準分類**：劃分為「景點」、「美食」、「住宿」三類。
- **群組稱呼優先**：地點中文優先採用群組對話中的慣用語（如「高空酒吧」、「夕陽晚餐峇里島風」、「超貴牛逼網美遊艇」等）。
- **行程標記**：標註哪些是暫定計畫已明確排入的項目（The Oxygen 列為 暫定 11/25 (三) 晚餐、洗大象列為 暫定 11/26 (四) 半日遊），其餘保持 -。
- **客觀評語**：備註去除個人姓名，純粹保留客觀評語與特色亮點提醒。

### 2. 預定計畫行程 (11/25 ~ 11/27 芭達雅 3 天暫定計畫)
- **欄位規劃**：日期 / 星期 ➔ 時段 / 順序 ➔ 行程想法 / 項目 ➔ 實際地點 (未提及則保持空白) ➔ **交通方式 (後續填充)** ➔ 備註。
- **忠實於文字紀錄，不擅自猜測加入未定地點，交通欄位留白方便後續補充填寫**：
  - **11/25 週三**：
    - （1）機場到巴達雅3小時（地點空白，交通留白，備註：第一天去芭達雅包車研究預訂來回）
    - （2）先去 check in（地點空白，交通留白）
    - （3）夕陽晚餐峇里島風（指定地點：The Oxygen Beachfront Oasis，交通留白，備註：先在 KKday 訂好位子）
    - （4）晚上夜市或是巴達雅步行街（夜店街）（地點空白，交通留白）
  - **11/26 週四**：
    - （1）早晨（起得來的話可以排早餐或是直接玩飯店設施）（地點空白，交通留白）
    - （2）半日遊：洗與餵食大象（指定地點：Elephant Jungle Sanctuary Pattaya，交通留白，備註：中午 12:00 至下午 17:00）
    - （3）可排（咖啡廳或是晚餐）（地點空白，交通留白）
    - （4）夜市或按摩（地點空白，交通留白）
  - **11/27 週五**：
    - （1）沙灘日（指定範例：例：粉紅沙灘、Dongtan Beach，交通留白）
    - （2）晚上夜市或按摩（地點空白，交通留白）

### 4. 影片提到地點 (8 部 YouTube 攻略地點全收錄 + 雙實景圖片)
- **米其林指南精選專區**：獨立彙整 13 處米其林必比登（Bib Gourmand）與星級入選推薦名店（如榮泰米粉、Somsak 螃蟹粉絲煲、艾海鮮、Elvis Suki、Lay Lao 等）。
- **全部影片詳細時間軸地點一覽**：逐項收錄 8 部影片提及之所有美食、景點、住宿與商場設施（共 110 處地點），附精確 YouTube 影片秒數直連超連結。
- **精準實景雙截圖嵌入**：已移除冗餘的「所屬影片」欄位，於表格最後新增「圖片 1 (環境/外觀/招牌)」與「圖片 2 (餐點/特色/設施)」，每張圖片皆經過逐幀仔細審查，確保呈現真實店家招牌、代表餐點特寫或景點核心設施，並標準化為 110x72 px 居中嵌入儲存格中（共嵌入 220 張實景影格縮圖）。
- **不影響其他 Sheet**：採獨立分頁呈現，原有「曼谷行程心願清單 (28張圖片)」、「預定計畫行程」及「影音參考」完全維持原貌、圖片與格線樣式。
